## Objetivo principal

Criar um esqueleto de site para a DCON com estrutura estratégica de páginas, blocos, H1, H2 e H3.

O site deve posicionar a DCON como uma contabilidade consultiva, técnica e estratégica para empresas que precisam de segurança fiscal, tributária, societária, trabalhista e contábil.

## Regras de construção

1. Não criar promessas exageradas.

2. Não usar linguagem genérica de “contabilidade barata”.

3. Não escrever como agência de marketing superficial.

4. Usar linguagem técnica, clara e empresarial.

5. Criar estrutura pensando em SEO, autoridade e conversão.

6. Separar páginas institucionais, páginas de serviços, páginas por segmento, páginas de captura e páginas de conteúdo.

7. Cada página deve ter:

   - objetivo da página;

   - intenção de busca;

   - H1;

   - H2 principais;

   - H3 sugeridos;

   - CTA principal;

   - CTA secundário;

   - observação estratégica.

8. Quando faltar informação, crie campos com “[preencher]”.

9. Organize tudo para que eu possa editar depois em versões.

10. Sempre pense em como essa página pode gerar autoridade, tráfego e lead.
